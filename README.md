# 学期课表与冲突检测

一个运行在 HarmonyOS PC（2in1）上的本地课表应用：导入或录入课程后自动标记时间冲突，用周视图展示课表，并分屏查看课表与待办。数据全部保存在本机，无需联网。

## 功能特性

- **课程录入**：表单录入课程名、星期、节次区间、周次区间、教室、教师；点击课表上的课程卡片即可编辑或删除。
- **批量导入**：粘贴多行文本批量导入，支持两种写法（见下方「导入格式」），格式不正确的行会被跳过并在提示中给出数量。
- **自动冲突检测**：同一星期、节次区间重叠且周次区间重叠的两门课判定为冲突。冲突课程以**红色底 + 红框 + 「冲突」角标**高亮，面板右上角与底部状态栏同步显示冲突处数与涉及课程数。
- **周视图课表**：周一至周日 × 第 1~12 节的网格，左侧显示节次与上课时间，跨节课程按高度跨行显示；顶部可切换上一周/下一周，课表按当前周次过滤。
- **分屏查看**：默认左右分屏（左侧课表、右侧「今日课程 + 待办清单」），工具栏一键切换为上下分屏。
- **待办清单**：手动添加、勾选完成、删除；支持「由今日课程生成待办」。
- **本地持久化**：课程、待办、当前周次、总周数均保存在本机 Preferences 中，重启应用后自动恢复。

## 目录结构

```
entry/src/main/ets/
├── model/
│   ├── Models.ets      # 数据模型、配色常量、导入解析、冲突检测算法

└── pages/
    └── Index.ets       # 主界面：工具栏 / 周视图 / 待办面板 / 录入与导入浮层
```

## 导入格式

每行一门课程，用逗号（也支持中文逗号、制表符、分号）分隔，以 `#` 开头的行为注释。

```
课程名, 星期, 开始节, 结束节, 起始周, 结束周, 教室, 教师
高等数学 A, 周一, 1, 2, 1, 16, 教一101, 张明
```

也支持区间写法：

```
课程名, 星期, 节次区间, 周次区间, 教室, 教师
大学英语, 周二, 3-4节, 1-16周, 外语楼203, 李华
```

星期可写「周一」或「1」；节次与周次只填一个数字时视为单周/单节。

## 运行方式

1. 用 DevEco Studio 打开本项目。
2. 配置签名：`文件 > 项目结构 > 签名配置`，勾选 `Automatically generate signature`（需登录华为账号，且模拟器/设备需处于启动状态）。
3. 在顶部设备下拉中选择运行目标：
   - `Previewer`（预览器）：无需签名，最快看到界面；
   - 本地模拟器（2in1 机型，如 MateBook Pro）或真机：需要签名。
4. 点击 `Run 'entry'`。

开发环境：DevEco Studio 6.0.1、HarmonyOS SDK 6.0.1(21)、`deviceTypes: ["2in1"]`。

## 技术要点

- ArkTS + ArkUI 声明式语法，单 Ability（Stage 模型）。
- 冲突判定：`a.day === b.day` 且节次区间重叠 且 周次区间重叠。
- 周视图使用 `Stack` + `position` 定位课程卡片，按节次高度换算纵向偏移，实现跨节卡片。
- 数据存储使用 `@kit.ArkData` 的 Preferences，应用不申请网络权限。
